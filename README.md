# 🎓 education.in - Modern Academic Institution & Research Center Website

A modern, responsive, and premium multi-page website built for **education.in**, designed with a trusted neutrals and deep blue academic aesthetic.

---

## 🌟 Key Highlights & Features

* **Design Palette**: Trusted Neutrals paired with Deep Oxford Blues and subtle gold academic accents.
* **Architecture**: Fully modular 5-file architecture (4 rich semantic HTML5 pages + 1 master CSS design system).
* **Interactive Tuition & Scholarship Estimator**: Live calculator on the homepage to compute merit scholarship waivers (up to 50%) and net semester fees in real time.
* **Academic Program Catalog**: Course explorer with instant category filtering (AI & Computing, Management, Data Science, Design) and live keyword search.
* **Interactive Curriculum Syllabus Viewer**: Built-in modal dialog to review semester-by-semester module syllabi and course outcomes.
* **Admissions Inquiry Desk**: Interactive consultation form with real-time field validation and assigned reference docket notifications.
* **Admissions FAQ Accordion**: Expandable questions and answers addressing entrance cutoffs, hostels, scholarships, and foreign visas.
* **Fully Responsive**: Mobile-first navigation drawer, sticky blur header, and CSS grid layouts that adapt to desktops, tablets, and mobile devices.

## 🚀 Running Locally

### Option 1: Direct File Opening
Double-click `index.html` to open it in any modern browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server
Using Python:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.

Using Node.js:
```bash
npx serve .
```

## 🌐 Deploying to GitHub Pages (Free Hosting)

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/education-website.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository:
   * Go to **Settings** > **Pages**.
   * Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
   * Click **Save**.
3. Your website will be live at `https://YOUR_USERNAME.github.io/education-website/`!
